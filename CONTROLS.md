# Pocket Controls

| Button | Behavior |
| --- | --- |
| D-pad | Move the cursor; steer while driving; navigate the keyboard |
| A | Primary click; open an active text field; select virtual key |
| Y | Secondary click |
| B | Escape / Back; close keyboard |
| X | Space in gameplay; delete while typing |
| Start | Enter / confirm text |
| Select + D-pad | Fine cursor movement |
| Select + Start | Open/close virtual keyboard manually |

Point to the editable name, price or save-name field and press A. The keyboard uses alphabetic or numeric keys as appropriate and moves to the top for fields near the bottom. Release a held A before selecting the field. Start confirms, X deletes, and B closes the overlay.
